# Security Policy

## Supported Access Policy

This section describes who is allowed to access the system and under which conditions.

| Requirement                      | Mandatory |
| -------------------------------- | --------- |
| Registered account in the system | ✅         |
| Verified personal data           | ✅         |
| Valid university ID number       | ✅         |
| Unique account per university ID | ✅         |

Only users who meet **all** the above requirements are allowed to access the system.

---

## Authentication & Account Security

* Access is restricted to users with pre-approved accounts.
* Each account is linked to **one unique university number**.
* Duplicate accounts using the same university ID are strictly prohibited.
* Strong passwords are required for all users.
* Multiple failed login attempts will result in temporary account lockout.

---

## Data Protection

We take student data security seriously.

* Personal data and university numbers are stored securely.
* Sensitive information is protected using secure encryption methods.
* Data is accessible only to authorized system administrators.
* Secure communication channels are enforced (HTTPS).

---

## System Capacity & Abuse Prevention

* The system is designed to handle a large number of users simultaneously.
* Automated access, bots, and suspicious activities are actively monitored.
* Protective measures are in place against abuse and system overload.

---

## Reporting a Security Issue

If you discover a security vulnerability:

* Report it directly to the system administration.
* Do not disclose the issue publicly.
* All reports are handled confidentially.

We appreciate responsible disclosure to help keep student data safe.

---

## Enforcement

Violation of this security policy may result in:

* Temporary or permanent account suspension.
* Administrative action as deemed necessary by system management.

---

## Updates

This security policy may be updated at any time to ensure continued protection and system integrity.

Use of the system implies acceptance of this policy.
